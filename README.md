QuizNova – Modern Online Quiz Maker

QuizNova is a futuristic, fully responsive Online Quiz Maker web application built using HTML, CSS, and JavaScript. It features a premium SaaS-style UI design with glassmorphism effects, neon accents, and smooth animations, delivering a modern and interactive user experience.

Designed with a dark theme (deep navy blue background) and vibrant cyan & electric purple accents, QuizNova focuses on clean aesthetics, usability, and performance — making it ideal for portfolios and real-world frontend demonstrations.

✨ Features
🧠 Create custom quizzes with multiple-choice questions
🎯 Live quiz mode with interactive question flow
⏱️ Timer-based quiz experience
📊 Real-time progress tracking
🏆 Automatic score calculation system
📱 Fully responsive design (mobile, tablet, desktop)
💡 Animated statistics dashboard
❓ Interactive FAQ accordion section
🎉 Result page with detailed score breakdown
🔥 Smooth hover effects, transitions, and micro-interactions
