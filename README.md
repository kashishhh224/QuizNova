# 🚀 QuizNova – Modern Online Quiz Maker

QuizNova is a fully responsive and interactive **Online Quiz Maker web application** built using HTML, CSS, and JavaScript.  
It features a modern SaaS-style UI with glassmorphism effects, neon accents, and smooth animations, delivering a premium user experience.

---

## ✨ Features

- 🧠 Create custom quizzes with multiple-choice questions  
- 🎯 Interactive live quiz mode  
- ⏱️ Timer-based quiz experience  
- 📊 Real-time progress tracking  
- 🏆 Automatic score calculation  
- 📱 Fully responsive (mobile, tablet, desktop)  
- 💡 Animated statistics dashboard  
- ❓ FAQ accordion section  
- 🎉 Detailed result & score breakdown page  
- 🔥 Smooth transitions and micro-interactions  

---

## 🎨 UI/UX Highlights

- 🌌 Dark SaaS-style interface  
- 💎 Glassmorphism UI components  
- ⚡ Neon cyan & purple accents  
- 🎭 Smooth animations and hover effects  
- 🧩 Clean and modern layout
